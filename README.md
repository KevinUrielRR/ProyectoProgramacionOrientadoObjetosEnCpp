# PROYECTO PROGRAMACION ORIENTADO A OBJETOS EN C++
# CREACION DE OBJETOS : AEREONAVES

Proyecto escolar de la realización de un programa orientado a objetos que consistió en seleccionar un objeto y representar su existencia mediante código identificando lo que puede hacer y las características que tiene, así mismo, programando las clases base y derivadas, atributos, métodos; haciendo uso de los paradigmas de programación orientado a objetos.
